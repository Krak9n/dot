### Hyprland shortcuts
---
```bash
ALT + Enter				# kitty terminal  
ALT + Z 	 			# zathura  
ALT + SHIFT + Q			# close a window  
Print 		  	  		# do a screenshot  
ALT + T 		    	# thunar   
ALT + B 		  		# firefox  
ALT + D					# hyprlauncher  
ALT + SHIFT + Enter 	# nvim in kitty  
ALT + E		  			# emacs   
ALT + G 				# discord  
  
ALT + F					# fullscreen current window
ALT + SHIFT + H/J/K/L 	# resize a window
ALT + H/J/K/L 			# change focus
```
