**/scripts** on the other hand contains the scripts I rely on everyday.  
  
Respectively:
+ C is Ctrl.    
+ M is Alt.  
+ Uppercase letter is the one with Shift held.  

### Hyprland shortcuts
---
```bash
M-Enter				# kitty terminal  
M-Z 	 			# zathura  
M-Q					# close a window  
PrtSc 		  	  	# do a screenshot  
M-T 		    	# thunar   
M-B 		  		# firefox  
M-D					# hyprlauncher  
M-Shift-Enter	 	# nvim in kitty  
M-E		  			# emacs   
M-G 				# discord  
M-F					# fullscreen current window
M-H/J/K/L		 	# resize a window
M-h/j/k/l 			# change focus  
```  
   
### TMUX shortcuts
```bash
CTRL + A				# prefix
C-a + h/v				# split horizontally/vertically
C-a C-h/j/k/l			# resize pane
C-a h/j/k/k				# change focus
C-a [ 					# copy-mode
C-a v 					# begin-selection
C-a y					# yank
C-a p					# paste
```
